# PRL0 0.1.0 — PearlHash / Kryptex / HiveOS / 0% dev fee

PRL0 is a source/build kit for a Pearl (PRL) miner aimed at NVIDIA Ampere cards such as the RTX 3060 Ti (SM86). It uses the open-source MIT/Apache-2.0 `puneet-mehta/pearl-hashrate-miner` CUDA/proof implementation and adds a native Pearl Stratum client for Kryptex plus HiveOS Custom Miner integration.

**Developer fee in PRL0: 0.00%.** There is no developer wallet, no timed wallet switch and no hidden fee path in `src/kryptex_miner.rs`.

This does **not** patch ForgeMiner, Fl4shMiner, PearlFortune or any other closed miner. It is a separate implementation built from permissively licensed source.

## Current validation status

The source and HiveOS wrapper are prepared, and the shell scripts pass syntax validation. This environment does not have CUDA/nvcc, Docker, a 3060 Ti, or outbound Git access, so the binary has **not been compiled or live-tested against Kryptex here**. Do not treat a displayed TH/s value as proof of valid mining: confirm accepted shares on Kryptex.

The performance target for a tuned RTX 3060 Ti is the same class as current commercial miners. For reference, Fl4shMiner publishes about 68 TH/s on a 3060 Ti at locked core 1825 MHz / +225 core / memory 5001 MHz / 168 W. PRL0 cannot honestly guarantee that number until it is benchmarked on your exact card/driver; the code exposes three matrix shapes to tune Ampere without introducing a fee.

## What is included

- `src/kryptex_miner.rs` — Rust pool miner; TCP Pearl Stratum, multi-GPU, PlainProof submission, 0% dev fee.
- `hiveos/h-manifest.conf` — HiveOS custom-miner manifest.
- `hiveos/h-config.sh` — translates Flight Sheet fields to PRL0 environment variables.
- `hiveos/h-run.sh` — launcher/logging.
- `hiveos/h-stats.sh` — per-GPU TH/s, temperature, fan and accepted/rejected shares for HiveOS.
- `build_from_upstream.sh` — clones the open-source CUDA base, injects PRL0, builds the CUDA fatbin + Rust binary, and creates the HiveOS tarball.
- `Dockerfile.build` / `docker-build.sh` — reproducible Ubuntu 22.04 + CUDA 12.8 build path.

## Build on a PC with Docker

From this folder:

```bash
./docker-build.sh
```

The output should be:

```text
dist/prl0-0.1.0.tar.gz
dist/prl0-0.1.0.tar.gz.sha256
```

The Docker build downloads `puneet-mehta/pearl-hashrate-miner`, builds `pearl_gemm.fatbin`, compiles `prl0-kryptex` in release mode, and packages the files in a top-level `prl0/` directory expected by HiveOS.

You can also build without Docker if the machine already has Rust, Git and CUDA/nvcc:

```bash
./build_from_upstream.sh
```

## HiveOS install/config

After building, host `prl0-0.1.0.tar.gz` at a URL reachable by the rig, or copy/extract it manually under `/hive/miners/custom/`.

Recommended Custom Miner fields:

```text
Miner name:       prl0
Hash algorithm:   pearlhash
Pool URL:         prl-eu.kryptex.network:7048
Wallet template:  %WAL%.%WORKER_NAME%
Password:         x
Extra config:     shape=small
```

`h-config.sh` strips the `.WORKER_NAME` suffix before authorizing because PRL0 sends `wallet` and `worker` as separate fields.

Kryptex also supports `username/worker` instead of a PRL wallet if you use its account/auto-exchange mode. TCP port 7048 is the default in PRL0. SSL port 8048 is **not implemented in PRL0 0.1.0**.

## RTX 3060 Ti tuning

Start with:

```text
shape=small
Core absolute: 1700–1825 MHz
Memory: stock/low (PearlHash is primarily core/tensor heavy)
Power limit: 150–170 W
```

Then compare:

```text
shape=small
shape=big_m
shape=huge_m
```

Use the shape that gives the highest stable **accepted-share hashrate**, not merely the largest local number. The upstream CUDA base provides SM86 kernels and multi-GPU support; PRL0 reports local TH/s as `(m × n × k × iterations/sec) / 1e12`.

## Pool/protocol notes

PRL0 uses the object-style Pearl Stratum dialect:

```text
mining.authorize {wallet, worker, pass, agent}
mining.notify    {header, height, job_id, target, ...}
mining.submit    {job_id, plain_proof}
```

`plain_proof` is generated by the upstream proof builder and sent as `bincode::serialize(PlainProof)` encoded in Base64. The miner accepts new optional notify fields, but rejects an explicitly advertised `cert_version` other than 3 to avoid silently mining a cryptographically incompatible legacy job.

## Important: pool fee vs miner fee

PRL0 has **0% miner/dev fee**. Kryptex itself can still charge its **pool fee**. Removing the miner fee does not remove the pool's fee or change its payout method.

## Build with GitHub Actions (no local CUDA toolkit required)

The kit also includes `.github/workflows/build-hiveos.yml`. Put the kit in a GitHub repository and run **Actions → Build PRL0 HiveOS → Run workflow**. The workflow compiles inside the CUDA 12.8 Docker image and uploads `prl0-0.1.0.tar.gz` as an Actions artifact. A GPU is not required to compile; a real NVIDIA GPU is still required to validate performance and accepted shares.
